# Development roadmap

1. **Foundation** — establish the UI, navigation, sample discovery, database setup, documentation, and foundation tests.
2. **Accounts and profiles** — add Supabase authentication, secure session refresh, return paths, onboarding, and public profile controls.
3. **Live discovery (implemented)** — replace fixtures with paginated problems, enable secure publishing and management, and query the category catalog.
4. **Connections (implemented)** — support transactional requests and responses, request history, and activity.
5. **Contact exchange and safety (implemented)** — implement sharing, revocation, blocking, reporting, and role-specific integration tests.
6. **Social and discovery improvements** — add engagement and refine filtering and recommendations after verifying the core journey.
7. **Deployment and validation** — configure hosted services, validate production permissions and redirects, and gather feedback from an initial community.

The [launch runbook](LAUNCH.md) covers production configuration, rollout order, and acceptance checks.
